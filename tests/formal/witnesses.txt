# CX formal parse-layer witness corpus
# Transcribed verbatim from spec/02-inprogress/formal/{lexicon.ebnf,grammar.ebnf,
# parser-rules-for-cx-meaning.txt}. Each row is a CX→XML (or CX→<cx:err>) witness.
#
# Format (TAB-separated, 5 fields):
#   id <TAB> mode <TAB> kind <TAB> input <TAB> expect
#
#   id     = rule id + sequence (e.g. LX-INT-1)
#   mode   = data | program        (program rows are deferred in harness pass 1)
#   kind   = doc  -> compare emit_formal_doc(parse(input))  (whole-document image, M-DOC)
#            node -> compare emit_formal_node(single root node)  (node-in-isolation image)
#            err  -> input is rejected; expect carries <cx:err code offset>
#   input  = the CX source. Literal newline encoded as the marker <NL>.
#            Backslashes are LITERAL (so '\n' is a CX escape, two chars).
#   expect = canonical XML, or the <cx:err .../> for err rows.
#
# The xmlns:cx binding mandated on the document root (parser-rules §P1-6) is
# ELIDED here exactly as in the witness rows; the harness compares modulo it.
# The two raw-byte witnesses (LR-UTF8 <0xFF>, LR-BOM <BOM>) are handled in-code,
# not here (their input is not a UTF-8 string).

# CX Conformance — Apache Arrow C-Data interop round-trips
# Version: 0.3 — 2026-05-09 (Phase 7.74c-conformance-runner)
# Covers: spec/abi.md §2.11, spec/decisions/0015 D9 (libcx_arrow).
#
# Verification model. Apache Arrow's binary form is not stable across
# versions, so we cannot assert exact Arrow bytes. These fixtures are
# round-trip identity tests instead:
#   1. parse(in_cx) → emit_data_bin_chunked(chunk_size=chunk_at) → bytes_in
#   2. arrow.round_trip_cxdb(bytes_in) → bytes_out (CXDB → Arrow → CXDB
#      via libcx_arrow's export + import paths)
#   3. parse_data_bin(bytes_in) and parse_data_bin(bytes_out) emit
#      structurally equivalent CX text (every value in `expect_values`
#      appears in both).
# Optional assertions:
#   --- arrow_children_formats   per-column Arrow format strings (one per line)
#   --- arrow_chunk_lengths      per-emitted-chunk row counts (one per line)
#   --- expected_export_error    substring of expected error from
#                                arrow.round_trip_cxdb (negative case)
#
# Section format follows the conformance runner's `=== test:` /
# `--- section` shape (see vcx/tests/runners/conformance/conformance_run.v
# for the parser; the arrow runner reuses it). Comments after `# `
# inside any section are stripped by the runner.
#
# Supported v0.6.0 column types (all 10):
#   int / i64    →  Arrow 'l'    int64
#   i8           →  Arrow 'c'    int8
#   i16          →  Arrow 's'    int16
#   i32          →  Arrow 'i'    int32
#   float / f64  →  Arrow 'g'    float64
#   bool         →  Arrow 'b'    bool, bit-packed
#   string       →  Arrow 'u'    utf8
#   date / d     →  Arrow 'tdD'  date32
#   datetime     →  Arrow 'tsn:UTC' timestamp[ns, UTC]
#   bytes        →  Arrow 'z'    binary
#
# Deferred (must surface a clear `not yet supported in v0.6.0` error):
#   decimal, dictionary columns.

=== test: arrow-011-datetime-offset-normalizes
level: extended
tags: arrow roundtrip datetime canonical_offset
chunk_at: 1024
# Strict canonical normalizes datetime offsets to UTC: +02:00 is
# normalized to Z on the wire. Round-trip therefore returns Z form.
--- in_cx
[evts :table[name:string when:datetime]
  beta 2025-06-30T23:00:00+02:00
]
--- arrow_children_formats
u
tsn:UTC
--- expect_values
2025-06-30T21:00:00Z

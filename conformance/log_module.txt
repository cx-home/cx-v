# log: structured-logging module conformance suite
# Version: 1.0 — 2026-05-18 (FF10 per spec/v0_7_0_status.md / spec/modules/log.md §6)
#
# Cross-binding byte-identity discipline. Every fixture below must
# pass byte-identical on V + Python + Go + Rust + TypeScript when each
# binding's eval_cxl wrapper routes through the shared C ABI (per FF9).
#
# Five fixture categories per spec/modules/log.md §6:
#
#   1. Format byte-identity — fixed input + format → byte-identical bytes
#   2. Level filtering      — each level × min-level combination
#   3. Context inheritance  — nested with-context composes + restores
#   4. Pure-only refusal    — every log:* emitter refused under pure-only
#   5. Output sink          — file:/stderr/stdout dispatch (file: only at v0.7.0)
#
# Naming: `logmod-NNN-slug` where NNN is the 3-digit fixture number.
# Tags include the function row (FF1..FF8), the ADR 0023 / spec/modules/log.md
# section, and an optional `cross-binding` marker for byte-identity tests.
#
# Runner integration: the `out_log` section drives FF10's byte-identity
# discipline. The runner injects `[?cx log-output=file:<tmp>]` +
# `[?cx test-mode=true]` ahead of the in_cxl program; after evaluation
# it reads the temp file and compares against `out_log` byte-identically
# (after a trim of leading/trailing newlines, mirroring parse_suite).
#
# `out_err` covers pure-only refusal via cx-err:CXER0040 substring.
# `out_text` covers log:level() — the lone ReadOnly value-returning fn.

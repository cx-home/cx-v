# CX Conformance — cx diff (ADR 0012)
# Version: 1.0 — 2026-05-08
# Covers: data-equivalence, attribute changes, element changes, body
#         changes, type-annotation changes, format outputs (unified/
#         json/summary), exit-code semantics.
#
# Each test runs `cx diff` on `in_a` and `in_b`. The empty
# `expected_unified` / `expected_summary` sections mean "no output
# expected" (data-equivalent inputs); the runner asserts the output
# is empty AND that the change list is empty.

=== test: 001-data-equivalent-identical
level: core
tags: diff equiv

--- in_b
[server host=localhost]
--- expected_unified

--- expected_summary
no changes

# CX Conformance — data_bin chunked-table round-trips
# Version: 0.2 — 2026-05-09 (V core impl landed in Phase 7.72)
# Covers: spec/data_bin.md §3.11, spec/decisions/0015 D1.
#
# Verification:
#   1. parse(in_cx) → emit_data_bin_chunked(chunk_size=chunk_at) →
#      hex(bytes) == out_data_bin_hex
#   2. cx_from_data_bin(bytes) → emit_cx round-trips the data
#      (logical equivalence; presentation-form may differ — fixtures
#      verify byte form here, not text round-trip).
#
# Hex notation: bytes are space-separated, two hex digits each.
# Comments (text after `# `) are non-normative; the byte sequence is
# the test value. The runner strips the framing prefix
# `[u32 LE size]` before comparing — fixtures record the CXDB header
# onward.
#
# Embedding: a `[name :table[...]]` document encodes as
# `<header> 0x50 0x01 <key=name> <chunked-table>`. The chunked-table
# value (tag `0x63`) carries no element name itself; the wrapping
# single-pair map preserves the name. See spec/data_bin.md §3.11.1.
#
# `chunk_at: N` metadata sets emit_data_bin_chunked's chunk_size for
# this fixture; default is 2^20 (the strict-canonical value, ADR
# 0015 D1) when absent.

=== test: ch-006-chunked-datetime-column-zulu
level: extended
tags: data_bin chunked datetime
# Phase 7.74c-datetime-foundations — strict-cell datetime wire form
# per spec/data_bin.md §3.6.1 / §3.10.3. Each cell is 12 bytes:
# i64 unix_nanos LE + i16 offset_minutes LE (always 0 in canonical) +
# u16 reserved (zero). 2024-01-15T12:34:56Z = 1705322096 s since epoch
# = 1705322096000000000 ns = 0x17AA85693FB46000.
--- in_cx
[evts :table[name:string when:datetime]
  alice 2024-01-15T12:34:56Z
]
--- out_data_bin_hex
43 58 44 42 01 01 40 00 00 00 00 00   # header
50 01 30 04 65 76 74 73                # map / key "evts"
63 02                                  # chunked / col_count = 2
30 04 6E 61 6D 65 30                   # col 0 "name" / type 0x30 string
30 04 77 68 65 6E 32                   # col 1 "when" / type 0x32 datetime
14                                     # body_byte_len = 20
01                                     # body-tag = 0x01 (plain)
01                                     # row_count = 1
05 61 6C 69 63 65                      # col 0 row 0: "alice"
00 60 B4 3F 69 85 AA 17 00 00 00 00    # col 1 row 0: 1705322096000000000 ns, off=0, rsvd=0
00                                     # end-of-table

=== test: ch-007-chunked-datetime-offset-normalizes-to-utc
level: extended
tags: data_bin chunked datetime canonical_offset
# Strict canonical (spec §3.6.1) normalizes datetime offsets to UTC:
# offset_minutes is always 0 on the wire and unix_nanos already
# encodes UTC. 2025-06-30T23:00:00+02:00 = 2025-06-30T21:00:00Z =
# 1751317200 s = 1751317200000000000 ns = 0x184DEDB6EB082000 LE.
--- in_cx
[evts :table[name:string when:datetime]
  beta 2025-06-30T23:00:00+02:00
]
--- out_data_bin_hex
43 58 44 42 01 01 40 00 00 00 00 00   # header
50 01 30 04 65 76 74 73                # map / key "evts"
63 02                                  # chunked / col_count = 2
30 04 6E 61 6D 65 30                   # col 0
30 04 77 68 65 6E 32                   # col 1 datetime
13                                     # body_byte_len = 19
01                                     # body-tag plain
01                                     # row_count = 1
04 62 65 74 61                         # col 0 row 0: "beta"
00 20 08 EB B6 ED 4D 18 00 00 00 00    # col 1 row 0: 1751317200000000000 ns (UTC-normalized), off=0
00                                     # end-of-table

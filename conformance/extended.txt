=== test: 042-eval-directive-single-slot
level: extended
tags: cxl eval-directive v3.6 adr-0017
# Grammar [59] post-ADR-0017: `[?Name ArgArray? ]` uniform shape.
# Every EvalDirective body is zero or one Array literal whose items
# are the positional slots (ADR 0017 §D6 / §D7). The single-slot
# disambiguation rule (resolution 2.i, 2026-05-12) forces the first
# `[…]` body item to parse as an Array regardless of comma presence
# — `[?if [cond]]` is an EvalDirective whose arg array has one
# textual slot, not an EvalDirective with a nested `cond` element.
--- in_cx
[?if [cond]]
--- out_ast
{
  "type": "Document",
  "elements": [
    {
      "type": "EvalDirective",
      "name": "if",
      "items": [
        {
          "type": "Array",
          "items": [{"type": "Text", "value": "cond"}]
        }
      ]
    }
  ]
}
--- out_cx
[?if [cond]]

=== test: 043-eval-directive-three-slot
level: extended
tags: cxl eval-directive v3.6 adr-0017
# Grammar [59] post-ADR-0017 §D7: three-slot `[?if [cond, then-body,
# else-body]]`. The `:then=…` / `:else=…` named-attribute slots

=== test: cmp-003-unknown-codec-rejected
level: extended
tags: data_bin compression error
# A row-group whose body-tag is 0x90 (compressed) but whose codec id
# is 0xFF (unknown) must be rejected at decode time. The chunked-
# table reader (parse_data_bin → read_chunked_table_payload) routes
# the wrapper through decompress_row_group which raises D005.
--- in_data_bin_hex
43 58 44 42 01 01 40 00 00 00 00 00    # CXDB header
63 02 30 04 6E 61 6D 65 30 30 05 73 63 6F 72 65 12  # 0x63 + 2 cols
07                                     # body_byte_len = 7
90                                     # body-tag 0x90 (compressed)
FF                                     # codec id 0xFF (unknown)
05 03                                  # uncomp_len=5, comp_len=3
DE AD BE                               # 3 frame bytes (garbage; rejected at codec-id check)
00                                     # end-of-table marker
--- expected_decode_error
D005: unknown compression codec id 0xff (zstd v1 = 0x01 expected)

=== test: cmp-004-codec-id-zero-rejected-in-canonical
level: extended
tags: data_bin compression canonical
# Codec id 0x00 ("no compression") is reserved per §3.12.1 and is
# illegal in canonical form. Use plain body-tag 0x01 instead.
# body_byte_len = 10 = body-tag(1) + codec(1) + uncomp_len(1) +
# comp_len(1) + 6 frame bytes (intentionally garbage; decode rejects
# at codec-id check before reading the frame).
--- in_data_bin_hex
43 58 44 42 01 01 40 00 00 00 00 00    # CXDB header
63 02 30 04 6E 61 6D 65 30 30 05 73 63 6F 72 65 12  # 0x63 + 2 cols
07                                     # body_byte_len = 7
90                                     # body-tag 0x90 (compressed)
00                                     # codec id 0x00 (reserved)
05 03                                  # uncomp_len=5, comp_len=3
DE AD BE                               # 3 frame bytes (garbage; rejected at codec-id check)
00                                     # end-of-table marker
--- expected_decode_error
D006: codec id 0x00 reserved; use plain body-tag 0x01 for uncompressed row groups
